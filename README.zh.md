# dsh-session-auto-rename

在 DeepSeek Harness 侧栏的会话菜单里新增 **自动重命名**，并让会话菜单可以 **右键呼出**。
English notes: [README.md](README.md)。

## 你会得到什么

- **自动重命名**：会话「…」菜单里、内置「重命名」的正下方多一行。它读取会话日志，按时间衰减给每条用户消息计权（τ = 3 天，越新的消息越主导主题），请当前默认模型给出短标题，再通过内置重命名 RPC 直接应用。运行期间底部状态行显示进度，失败会给出原因。
- **右键菜单**：在任意会话行上右键，该行原本的「…」菜单就在鼠标位置弹出。菜单内容仍是内置的那份（置顶 / 重命名 / 自动重命名 / 分叉 / 归档 / 复制 ID），不是重写的一套。
- **Agent 工具**：`session_auto_rename({ sessionId })`，与菜单项同一个操作，模型的工具面板里可见。

## 前置条件

- DSH `>= 0.2.1-rc.5`（Host 入口注册在共享的 `/api` Fetch 通道上，桌面壳只代理这个前缀）。
- 已配置默认模型。插件跟随输入框当前选择的默认模型，不自带 key。

## 安装

- **插件页 / 市场**：安装本 bundle 后**重启一次应用**——桌面壳启动时冻结页面要加载的插件清单，Client half 要等重启才出现。
- **命令行（web profile）**：
  ```sh
  dsh plugin --profile web add @jason25417/dsh-session-auto-rename
  ```
- **本地源码**：用宿主的插件管理器（`install_bundle`）把本目录作为 bundle 装入。

## 标题规则

- 宽度上限 **10 个汉字**；ASCII 字符按 0.5 个汉字宽度折算，因此纯英文标题最多 20 个字符。system prompt 里写明这条硬上限；仍超宽时会**追加一次改写请求**要求换更短的词，两次都超才退回截断。
- 时间衰减：`w = exp(-age / 3 天)`。按权重在 6000 字符预算内选最多 18 条消息，再按时间顺序连同「多久前 / 权重」一起给模型，所以话题中途转向时，标题跟着最近的方向走。
- 请求把推理档位压到最低（`off`），并且**不设超时**：模型跑多久等多久。再点一次会自动中断上一次并重开；页面关闭会让 Host 侧中断模型调用。
- 操作直接改名，不弹确认框；状态行会同时报出新旧标题。

## 已知限制

- 右键是「合成点击行内『…』按钮 + 让浮层菜单钉在鼠标点」。依赖侧栏行的 `data-row-key="session:<id>"` 与 `span[class*="rowActions"]` 结构；DSH 改版若改了这段 DOM，右键会静默失效（菜单行本身不受影响）。
- 标题请求走 `ctx.llm.stream`，用当前默认模型；在输入框切换模型会改变插件使用的路由。
- 菜单表面每帧按锚点重算位置，插件用 transform 把它钉在鼠标点，所以滚动页面时菜单跟着锚点移动，而不是留在原来的屏幕位置。

## 开发

纯 JS bundle：`index.js`（Host half：Fetch 路由 + Agent 工具）、`client.js`（Client half：菜单行、状态行、右键），由 `cordis.patch.yml` 接入。无构建步骤。

## 验证

在 DSH Desktop 0.2.1-rc.5（macOS）上验证：Host 的 `/api` Fetch 路由在约 2400 条事件的会话上返回标题耗时 2.5–4.4 s；Client 端菜单行位于「重命名」与「分叉会话」之间、尺寸与内置菜单项一致，右键在鼠标位置弹出同一菜单，点击能到达 Host（状态行 → 侧栏标题更新），空白会话行右键无反应。
